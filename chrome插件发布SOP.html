Chrome 插件发布 SOP

PromptLib — 从本地开发到 Chrome Web Store 上架全流程

一、注册开发者账号

  1. 打开 Chrome 开发者控制台：https://chrome.google.com/webstore/devconsole
  2. 使用你的 Google 账号登录
  3. 支付一次性注册费 $5（支持信用卡 / 借记卡）
  4. 注册完成后即可进入开发者控制台
注意：注册费是一次性的，支付后可以发布无限数量的插件。

二、准备上架材料

必填项

材料要求
扩展 zip 包将 dist/ 目录内部文件打包为 .zip（不是 dist 文件夹本身）
名称PromptLib
简短描述最多 132 个字符，例如：「帮助 AI 大模型使用者在浏览器内实时管理和调用提示词模板」
详细描述功能介绍、使用方法，建议 200-500 字
商店图标128×128 PNG
截图至少 1 张，尺寸 1280×800 或 640×400，展示插件实际使用界面
类别选择「生产力工具 (Productivity)」
语言中文（简体）

可选但建议提供

材料说明
宣传图（小）440×280 PNG，商店列表展示用
隐私政策说明「本插件不收集任何用户数据，所有数据存储在用户本地浏览器」

三、打包

在项目根目录执行以下命令：

npm run build
cd dist
zip -r ../promptlib.zip .

生成的 promptlib.zip 即为待上传文件。

注意：打包前请确认 manifest.json 中的 version 字段。每次更新都需要递增版本号（如 1.0.0 → 1.0.1）。

四、提交审核

  1. 在开发者控制台点击「新建项目」
  2. 上传 promptlib.zip 文件
  3. 填写商店列表信息（名称、描述、截图等）
  4. 设置分发范围：
    • 公开 — 所有人可在商店搜索并安装
    • 不公开 — 仅有直接链接的人可安装（适合小范围分享）
  5. 点击「提交审核」

五、等待审核

  • 审核周期通常 1-3 个工作日，简单插件较快
  • 审核通过后自动上架，你会收到邮件通知
  • 如果被拒，邮件中会告知原因，修改后重新提交即可

六、分享给他人

审核通过后你会获得商店链接，格式如下：

https://chrome.google.com/webstore/detail/promptlib/xxxxxxxxxxxxxxxx

将链接发给他人，对方点击链接 → 点击「添加至 Chrome」→ 完成安装。

七、后续版本更新

  1. 修改代码
  2. 在 manifest.json 中递增 version（如 1.0.0 → 1.0.1）
  3. 执行 npm run build 并重新打包 zip
  4. 在开发者控制台上传新版本
  5. 提交审核，通过后所有已安装用户自动更新
